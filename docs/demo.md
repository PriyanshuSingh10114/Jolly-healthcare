## Presenter Checklist Before Hitting Record

1. **Browser Windows**:
   - Tab 1: Zoho Commerce Public Storefront (scrolled to top).
   - Tab 2: Zoho Creator Internal Application (`All_Plants` and `All_RFQs` bookmarked).
   - Tab 3: Code Editor open to `creator/deluge/validate-rfq.deluge` and `integration/src/server.js`.
2. **Clean Test State**:
   - Ensure the 3 dummy plants exist and are in `Synced` status.
   - Delete any previous test RFQ with buyer `rahul@example.com` and quantity `75000` (or use a fresh quantity like `85000` so the new record is unmistakably timestamped during the recording).
3. **Audio & Video Quality**:
   - 1080p or 1440p resolution.
   - 60 fps screen capture.
   - Clear, noise-cancelled microphone audio.
   - Ensure no API keys or private OAuth secrets appear on screen.
